# Contact Manager

App de práctica (React + Vite): agregar contactos con nombre, correo y teléfono, verlos en una tabla,
eliminarlos, y se guardan en `localStorage` (siguen ahí al recargar).

Sin Docker:

```bash
npm install
```

```bash
npm run dev
```

La versión que se muestra junto al título está en `src/App.jsx` (`const VERSION = 'v1'`).

Para dockerizarla, seguir `../guias/`.
